# 🏥 Clinic Management System

Desktop application for managing clinic operations such as patients and appointments.

---

## 📌 Overview
This project is built using **.NET Framework** and follows the **3-Tier Architecture** to practice backend design and business logic separation.

---

## ✨ Key Features
- Patient management
- Appointment scheduling
- Medical record handling
- Basic workflow logic
- Layered application structure

---

## 🏗 Architecture
- Presentation Layer (Windows Forms)
- Business Logic Layer
- Data Access Layer

---

## 🛠 Technologies Used
- C#
- .NET Framework
- SQL Server
- ADO.NET

---

## 🚀 Future Enhancements
- API-based backend
- Role-based access
- Reporting module
- Improved validation
